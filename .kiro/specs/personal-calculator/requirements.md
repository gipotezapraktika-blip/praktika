# Requirements Document

## Introduction

Личный калькулятор с графическим интерфейсом, похожим на стандартный калькулятор Windows. Предоставляет базовые арифметические операции и стандартный функционал для повседневных вычислений.

## Glossary

- **Calculator**: Основное приложение калькулятора
- **Display**: Область отображения чисел и результатов вычислений
- **Operation**: Арифметическая операция (сложение, вычитание, умножение, деление)
- **Memory**: Функция памяти калькулятора для сохранения значений

## Requirements

### Requirement 1: Базовые арифметические операции

**User Story:** Как пользователь, я хочу выполнять базовые арифметические операции, чтобы производить повседневные вычисления.

#### Acceptance Criteria

1. WHEN пользователь вводит два числа и выбирает операцию сложения, THE Calculator SHALL отобразить корректную сумму
2. WHEN пользователь вводит два числа и выбирает операцию вычитания, THE Calculator SHALL отобразить корректную разность
3. WHEN пользователь вводит два числа и выбирает операцию умножения, THE Calculator SHALL отобразить корректное произведение
4. WHEN пользователь вводит два числа и выбирает операцию деления, THE Calculator SHALL отобразить корректное частное
5. IF пользователь пытается разделить на ноль, THEN THE Calculator SHALL отобразить сообщение об ошибке

### Requirement 2: Ввод чисел

**User Story:** Как пользователь, я хочу вводить числа через интерфейс, чтобы выполнять вычисления.

#### Acceptance Criteria

1. WHEN пользователь нажимает цифровую кнопку, THE Calculator SHALL добавить цифру к текущему числу на Display
2. WHEN пользователь нажимает кнопку десятичной точки, THE Calculator SHALL добавить точку к текущему числу
3. IF пользователь нажимает кнопку десятичной точки повторно, THEN THE Calculator SHALL игнорировать повторный ввод
4. THE Calculator SHALL поддерживать ввод отрицательных чисел через кнопку смены знака

### Requirement 3: Очистка и удаление

**User Story:** Как пользователь, я хочу исправлять ошибки ввода, чтобы получать правильные результаты.

#### Acceptance Criteria

1. WHEN пользователь нажимает кнопку CE (Clear Entry), THE Calculator SHALL очистить текущий ввод
2. WHEN пользователь нажимает кнопку C (Clear), THE Calculator SHALL сбросить все вычисления и очистить Display
3. WHEN пользователь нажимает кнопку Backspace, THE Calculator SHALL удалить последнюю введенную цифру

### Requirement 4: Функции памяти

**User Story:** Как пользователь, я хочу сохранять промежуточные результаты в памяти, чтобы использовать их в последующих вычислениях.

#### Acceptance Criteria

1. WHEN пользователь нажимает кнопку MS (Memory Store), THE Calculator SHALL сохранить текущее значение Display в Memory
2. WHEN пользователь нажимает кнопку MR (Memory Recall), THE Calculator SHALL отобразить сохраненное значение из Memory
3. WHEN пользователь нажимает кнопку MC (Memory Clear), THE Calculator SHALL очистить значение в Memory
4. WHEN пользователь нажимает кнопку M+ (Memory Add), THE Calculator SHALL добавить текущее значение Display к значению в Memory
5. WHEN пользователь нажимает кнопку M- (Memory Subtract), THE Calculator SHALL вычесть текущее значение Display из значения в Memory

### Requirement 5: Отображение результатов

**User Story:** Как пользователь, я хочу видеть результаты вычислений, чтобы использовать их для дальнейшей работы.

#### Acceptance Criteria

1. WHEN пользователь нажимает кнопку равно, THE Calculator SHALL отобразить результат вычисления на Display
2. THE Display SHALL отображать числа с точностью до 15 значащих цифр
3. WHEN результат превышает максимальное отображаемое значение, THE Calculator SHALL использовать научную нотацию
4. THE Display SHALL обновляться в реальном времени при вводе чисел

### Requirement 6: Последовательные операции

**User Story:** Как пользователь, я хочу выполнять последовательные операции без нажатия равно, чтобы ускорить вычисления.

#### Acceptance Criteria

1. WHEN пользователь вводит число, выбирает Operation, вводит второе число и выбирает другую Operation, THE Calculator SHALL вычислить результат первой операции перед применением второй
2. WHEN пользователь нажимает кнопку равно несколько раз подряд, THE Calculator SHALL повторять последнюю Operation с последним операндом

### Requirement 7: Интерфейс пользователя

**User Story:** Как пользователь, я хочу использовать интерфейс, похожий на калькулятор Windows, чтобы быстро освоить приложение.

#### Acceptance Criteria

1. THE Calculator SHALL отображать кнопки для цифр от 0 до 9 в стандартной раскладке
2. THE Calculator SHALL отображать кнопки для операций +, -, *, / в правой части интерфейса
3. THE Calculator SHALL отображать Display в верхней части окна
4. THE Calculator SHALL отображать кнопки памяти (MC, MR, MS, M+, M-) над цифровыми кнопками
5. THE Calculator SHALL отображать кнопки CE, C и Backspace в верхней части под Display

### Requirement 8: Процентные вычисления

**User Story:** Как пользователь, я хочу вычислять проценты, чтобы выполнять финансовые расчеты.

#### Acceptance Criteria

1. WHEN пользователь вводит число, выбирает Operation, вводит второе число и нажимает кнопку процента, THE Calculator SHALL вычислить процент от первого числа
2. WHEN пользователь вводит число и нажимает кнопку процента без предварительной Operation, THE Calculator SHALL вычислить процент от текущего значения

### Requirement 9: Дополнительные функции

**User Story:** Как пользователь, я хочу использовать дополнительные математические функции, чтобы расширить возможности калькулятора.

#### Acceptance Criteria

1. WHEN пользователь нажимает кнопку квадратного корня, THE Calculator SHALL вычислить квадратный корень текущего значения Display
2. WHEN пользователь нажимает кнопку возведения в квадрат, THE Calculator SHALL возвести текущее значение Display в квадрат
3. WHEN пользователь нажимает кнопку обратного значения (1/x), THE Calculator SHALL вычислить обратное значение текущего числа
4. IF пользователь пытается вычислить квадратный корень отрицательного числа, THEN THE Calculator SHALL отобразить сообщение об ошибке
